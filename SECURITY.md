# Security policy

## Supported version

Security fixes are currently provided for the latest 1.0.x release candidate.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature when it is enabled for the repository. Do not open a public issue containing an exploit, credential, learner data or private course material. If private reporting is unavailable, contact the repository owner through the profile contact method and include only the minimum information needed to establish a secure follow-up channel.

The project does not require runtime network access and does not ship credentials. Never attach production H5P exports or host backups to a report unless they have been fully sanitized.
